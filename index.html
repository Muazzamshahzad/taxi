Free GitHub Pages Hosting Guide

Publish this exact VTC booking website live in 3 simple steps

1

Create a New Repository

Go to github.com/new. Name your repository (e.g., bcn-vtc-transfers), set it to **Public**, and click **Create repository**.

2

Upload index.html File

Inside your new repo, click **Add file ➔ Create new file**. Name the file exactly index.html. Paste this complete website code and click **Commit changes**.

3

Enable GitHub Pages

Navigate to **Settings ➔ Pages** (left sidebar). Under *Build and deployment*, set Source to **Deploy from a branch**, pick branch **main** / **root**, and click **Save**. Your site will be live at https://yourusername.github.io/bcn-vtc-transfers/!
